02 / Method

How I measure

The same four habits run through every project on this site.

01

Change one thing at a time

Each study fixes the model, the prompt and the data, then varies a single setting. HBC-RAG varies passages per hop. SpecLane varies one engine flag. A difference then has one possible cause.

02

Score without a judge

Character spans, exact match and held-out quality guards, not an LLM grader. Every number regenerates from saved runs, with no API spend and no judge drift.

03

Intervals, not single runs

Comparisons carry paired bootstrap intervals. Anything inside the interval is called noise, including the cases where my own result is not significant.

04

State what it does not claim

Every project page ends with its limits: one seed, small samples, no healthy class, one document per question. A result is only useful with its boundary.
