# Demo videos

The 27-second demo on each project page is a HyperFrames composition generated by `make.py` from real files on the
machine: a source excerpt from the project repository, the captured output of a command run locally, and a screenshot
of the live page. Paths inside `make.py` point at the original repositories and are not portable.

```bash
npx hyperframes init demos --example blank --non-interactive --skip-skills --resolution 1080p
cd demos && python3 ../make.py speclane     # writes index.html for one project
npx hyperframes render --output speclane.mp4
ffmpeg -i speclane.mp4 -vf scale=1280:720 -c:v libx264 -crf 27 -preset slow -pix_fmt yuv420p -movflags +faststart -an speclane.mp4.out
```
